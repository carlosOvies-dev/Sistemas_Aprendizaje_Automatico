# Sistemas de Aprendizaje Automático

Repositorio con las prácticas y proyectos desarrollados en la asignatura de **Sistemas de Aprendizaje Automático**.

## Índice de prácticas

| Carpeta | Práctica | Descripción breve | Estado |
| :--- | :--- | :--- | :--- |
| [`01_taxis_ny`](./01_taxis_ny) | Análisis de taxis de Nueva York | Limpieza de datos, redes neuronales con embeddings (`ModeloEntrenamiento`), PCA en 2D y análisis de anomalías (JFK). | Completada |

## Tecnologías y herramientas

* **Lenguaje:** Python 3.12
* **Gestor de entornos y dependencias:** `uv` (`pyproject.toml` y `uv.lock`)
* **Librerías principales:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, TensorFlow / Keras
